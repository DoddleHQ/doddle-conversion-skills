# Conversion Fundamentals (shared vocabulary)

Core terms every skill assumes.

- **Conversion rate** = conversions / visitors (or sessions), for a defined step.
- **Funnel** = ordered steps a visitor passes through; conversion is between adjacent steps.
- **Landing page** = a single-purpose page with one primary CTA.
- **A/B test** = two variants compared on a primary metric; significance via two-proportion z-test.
- **MDE** = minimum detectable effect, the smallest lift worth detecting.
- **Sample size** = visitors needed per arm to detect the MDE at given alpha/power.
- **Offer** = price + value metric + bonuses + guarantee + risk reversal.
- **LIFT model** = Value proposition, Relevance, Clarity, Urgency, Anxiety, Distraction.
- **CRO audit** = heuristic + analytics + research + technical review, prioritized.
- **Personalization** = variant per segment, with a fallback for unknowns.
- **Guardrail metric** = a metric that must not regress during an experiment.
